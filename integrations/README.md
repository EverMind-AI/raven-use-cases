# Integrations

This directory documents how Raven works with other projects, platforms, and tools.

Each integration must use its own directory and follow [`templates/integration.md`](../templates/integration.md). Store only Raven-specific workflows, configuration, skills, and examples here. Link to upstream source code instead of copying it.
